External Tools Directory / 外部工具目录
=======================================

1. ExifTool (REQUIRED / 必需)
   Download ExifTool for Windows from: https://exiftool.org/
   Extract "exiftool(-k).exe" and the "exiftool_files" folder here,
   and rename "exiftool(-k).exe" -> "exiftool.exe".
   Or install ExifTool into your system PATH.

   请从 https://exiftool.org/ 下载 Windows 版 ExifTool，
   将 "exiftool(-k).exe" 和 "exiftool_files" 文件夹放到本目录，
   并把 "exiftool(-k).exe" 重命名为 "exiftool.exe"（或加入系统 PATH）。

2. SQLite CLI (OPTIONAL / 可选)
   If you do not have Python 3 installed, download "sqlite-tools-win-*"
   from https://www.sqlite.org/download.html and place "sqlite3.exe" here.
   (If Python 3 is installed, the scripts use Python's built-in sqlite3.)

   如果电脑未安装 Python 3，可从 https://www.sqlite.org/download.html
   下载 sqlite3.exe 放到本目录（已装 Python 3 则无需额外下载）。
